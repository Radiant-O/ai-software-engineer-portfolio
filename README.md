# Radiant — AI & Software Engineer Portfolio

The source for Abiodun “Radiant” Bukoye's engineering portfolio. It presents production experience and detailed case studies for Baobab Turn, Pitupi, and WorkScale.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
```

The static site is generated in `out/` and can be deployed to any static host.

## Routes

- `/` — Portfolio and experience
- `/case-studies/baobab-turn/` — Voice-agent turn-taking system
- `/case-studies/pitupi/` — Sanitized conversational finance architecture
- `/case-studies/workscale/` — Agentic product engineering case study

Pitupi is intentionally documented at the responsibility-boundary level. Provider configuration, internal endpoints, secrets, and operational procedures are not included.
